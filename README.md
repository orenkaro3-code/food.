# האוכל של אורן: הזמנה מהשולחן

- `/?t=1`, `/?t=2`, `/?t=3`: עמוד ההזמנה של כל שולחן (לשם מובילים הברקודים)
- `/admin`: פאנל לעובדים. מציג הזמנות חיות עם צליל, קריאות למלצר, מצב כל שולחן וברקודים להדפסה

אין תשלום ואין מחירים. אוכלים רק במקום.

## העלאה ל-Vercel
1. ב-GitHub פותחים ריפו חדש בשם `oren-food` ומעלים אליו את כל הקבצים (index.html, admin.html וכו׳ צריכים להיות ישר בשורש הריפו, לא בתוך תיקייה).
2. ב-Vercel לוחצים Add New ← Project, בוחרים את הריפו ולוחצים Deploy.
3. בפרויקט ב-Vercel עוברים ל-Storage ← Upstash for Redis ← Create ← Connect.
4. עוברים ל-Deployments ← Redeploy.
5. פותחים את `/admin` ← לשונית "ברקודים" ← מדפיסים.

## איך זה עובד
לקוח סורק ושולח הזמנה. ההזמנה מופיעה בפאנל עם צפצוף, והעובדים מעבירים אותה בין השלבים: חדשה ← בהכנה ← מוכנה ← הוגשה.
טלפון שפתח פעם אחת את `/admin` נחשב טלפון של עובד. כשהוא סורק ברקוד של שולחן, נפתח לו מצב השולחן בפאנל ולא התפריט.
